# App screenshots

Captured from the packaged Tempo Time LIVE 0.1.0 app on macOS 15.7.7.
`audio` shows live music arriving through a selected BlackHole loopback channel;
`manual` shows the optional keyboard tap override while audio capture continues.
The recording itself is not included.

Original PNGs and lossless WebPs retain the actual 720 × 470 capture size. These
are native desktop captures with real window chrome, not web mockups or upscaled
Retina images.
